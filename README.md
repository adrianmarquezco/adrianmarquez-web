# adrianmarquez.es

Web personal de Adrián Márquez — emprendedor, empresario y creador de proyectos digitales.

## Stack

| | |
|---|---|
| **Tecnología** | HTML + CSS + JavaScript puro |
| **Build** | Sin build step — archivos estáticos directos |
| **Despliegue** | Coolify (auto-deploy en push a `main`) |
| **Dominio** | adrianmarquez.es |
| **Repo** | github.com/adrianmarquezco/adrianmarquez-web |

Sin frameworks, sin node_modules, sin dependencias.

